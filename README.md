# QuizPlay

QuizPlay is a modern interactive quiz website made with HTML, CSS, and JavaScript.

## Current features
- Modern Playground-style UI
- Home page
- Explore quizzes
- Search and filters
- Interactive quiz
- Automatic score calculation
- Result page
- Create your own quiz
- Custom quizzes saved in browser localStorage
- Responsive layout for mobile

## Run
Open `index.html` in a browser. No server is required.
